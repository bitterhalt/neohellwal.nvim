# Palettes

The `use_palette` is the gateway to all of NeoHellwal's palette configuration, with it you select which custom palette you want NeoHellwal to use, as well as selecting built-in palettes from the plugin source code.

## How to Use

The use palette option can be set both as a string specifying a palette you want to always be loaded, or a table where a specific palette is only loaded once NeoHellwal loads either the `dark` or `light` theme variant. Here's an example:

```lua
require("neohellwal").setup({
    -- Setting `use_palette` to be a string will make it so NeoHellwal loads the specified palette
    -- (in this case "doomone") on both `dark` and `light` theme variants.
    use_palette = "doomone",

    -- You can also set it as a table specifying which type of palette you want
    -- to load for each of NeoHellwal's theme variants.
    use_palette = {
        dark = "tokyonight",
        light = "doomone"
    },
})
```

You can also set a path for a Vim colorscheme template file. It must define `background`, `foreground`, `cursor`, and `color0` through `color15` as Vim globals.

Example contents using a [catppuccin-mocha](https://github.com/catppuccin/catppuccin) palette:

```vim
" Special
let wallpaper  = "/home/user/Pictures/wallpaper.png" " This option is ignored by NeoHellwal.
let background = "#1E1E2E"
let foreground = "#CDD6F4"
let cursor     = "#CDD6F4"

" Colors
let color0  = "#45475A"
let color1  = "#F38BA8"
let color2  = "#A6E3A1"
let color3  = "#F9E2AF"
let color4  = "#89B4FA"
let color5  = "#F5C2E7"
let color6  = "#94E2D5"
let color7  = "#BAC2DE"
let color8  = "#585B70"
let color9  = "#F38BA8"
let color10 = "#A6E3A1"
let color11 = "#F9E2AF"
let color12 = "#89B4FA"
let color13 = "#F5C2E7"
let color14 = "#94E2D5"
let color15 = "#A6ADC8"
```

And here's how you would configure NeoHellwal to load such template file using it's file path.

```lua
require("neohellwal").setup({
    use_palette = {
        -- Hellwal's default palette file is used here for demonstration.
        dark = os.getenv("HOME") .. "/.cache/hellwal/colors.vim"
        light = os.getenv("HOME") .. "/my/personal/file/path/template.vim",
    }
})
```

By default, both theme variants use Hellwal. NeoHellwal reads `~/.cache/hellwal/colors.vim`, generated by Hellwal using its upstream Vim template.

```lua
require("neohellwal").setup({
    -- Here are the default values set for the `use_palette` option.
    use_palette = {
        dark = "hellwal",
        light = "hellwal",
    },
})
```

## Built-in Palettes

NeoHellwal uses Hellwal's generated palette by default and also includes additional built-in palettes.

You can easily use any well-known colorscheme palette with NeoHellwal without much effort. If you don't want to use an auto-generated palette, you can select a built-in palette like "catppuccin" or "tokyonight".

To achieve this, just use the `use_palette` option with one of the following available colorscheme palette names that can be found in this [directory](../lua/neohellwal/palettes/)

To use any of the available built-in colorscheme palettes, simply specify one of the names from the list in the `use_palette` option.

```lua
require("neohellwal").setup({
    use_palette = "catppuccin-mocha"

    -- or

    use_palette = {
        dark = "doomone"
        light = "tokyonight"
    }
})
```

> [!IMPORTANT]
> I did not create nor do not own any rights to the colorschemes mentioned/present in the palettes/ directory.
> NeoHellwal simply takes a base stripped down 16 color template of each of the themes to create it's own nvim colorscheme settings.

\
If you want to actively use any of the themes present in NeoHellwal's palette/ directory, consider using their own Neovim colorscheme plugins (if they have it) for a more consistent experience than what you would get from using them within NeoHellwal.

### Hellwal

NeoHellwal uses Hellwal's generated Vim palette at `~/.cache/hellwal/colors.vim` by default; you do not need to set `use_palette`.

Unlike some other palette managers, Hellwal does not provide this template as an automatically generated output. First install Hellwal's upstream [`colors.vim` template](https://github.com/danihek/hellwal/blob/main/templates/colors.vim) in Hellwal's template directory, then run Hellwal to generate `~/.cache/hellwal/colors.vim`.

Hellwal's variables are mapped automatically: `g:hellwal_background`, `g:hellwal_foreground`, and `g:hellwal_cursor` map to the corresponding NeoHellwal colors; `g:hellwal_0` through `g:hellwal_15` map to `color0` through `color15`.
